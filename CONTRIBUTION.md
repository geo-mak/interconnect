# Contribution's policies and guidelines

## Authoring and communication

Feedbacks, suggestions and ideas are welcomed, but all related issues **must** be authored by humans.

This project does **not** endorse an open code-contribution model. 

Contributions in a form of code and documents will be authored by the project's members and delegated persons **only**.

The project's internal contribution's policy specifies the following:

- Code that is intended to get merged into the codebase **must** be **fully** written and audited by humans, in addition to all related **comments** and **documentations**. 

- All documentations and publications made available by this project **must** be **fully** written and audited by humans.

Contributors are free to use LLMs for anything else, as long the internal policy remains respected.
